# Deadly Era official website

A free, responsive, single-page website ready for GitHub Pages. The site uses no paid dependencies, trackers, or external CSS/JS frameworks.

## Publish with GitHub Pages

1. Sign in to https://github.com and create a new **public** repository named `deadly-era`.
2. Choose **Add file → Upload files** and upload `index.html` from this folder. Commit the change.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**. Choose `main` and `/ (root)`, then click **Save**.
5. Wait a few minutes. Your URL will be `https://YOUR-USERNAME.github.io/deadly-era/` (replace YOUR-USERNAME).

For a shorter root-domain URL, name the repository `YOUR-USERNAME.github.io` instead.

## Customize

Edit `index.html` to replace text, add band photographs, logo, upcoming shows, or a downloadable EPK. The YouTube embed and social links are already included.

## Notes

The design uses CSS gradients and typography rather than stock images. This avoids image licensing concerns and keeps loading fast. You can add original photos and your official logo later.
